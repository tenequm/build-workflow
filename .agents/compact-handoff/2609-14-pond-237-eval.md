### Three things that cost real time today

- **A codex worker has no network.** The adapter spawns `--sandbox
  workspace-write`, whose default denies it, and every worker reaches the task
  server over 127.0.0.1. A codex manager burned 530,230 input tokens diagnosing
  this and created zero tasks. The shim now passes
  `-c sandbox_workspace_write.network_access=true`.
- **A partial templates override is worse than none.** Ship a role directory for
  every role the seed declares; ship only `manager/` and the orchestrator's
  reassign correction silently skips every lens role.
- **Five smokes failed while the reviewer was right**, and every one was a fact the
  grader depended on that the goal text left to the model's discretion. First the
  function name, which prose could not carry (`88feb83`, `8f350d3`); then the
  category, which five labels and no routing rule made a coin flip (`4a25b17`).
  The pattern to watch for: a contract that names what a field may contain without
  saying what decides it.
- **Three smokes failed while the reviewer was right**, and the last one was the
  grader's fault. Runs one and two omitted the function name; run three named it
  in the prose and in an `identifier` key it invented, while the block's `claim`
  had been paraphrased down to a sentence without it. Prose is not a durable
  carrier for a machine-read fact - it needed a schema slot. `8f350d3` made
  `identifier` a required field compared exactly, and made a contract-breaking
  block MALFORMED rather than MISSED, so the next one is diagnosed in the run that
  produced it.
- **The harness is linted by `bernstein_operator`'s ruff config, not
  `bernstein_herdr`'s.** Formatting it from the wrong project's directory passes
  locally and fails the pre-commit hook: `cd bernstein_operator && uv run ruff
  format --config pyproject.toml ../fixtures/review-pr-cases/harness.py`.
