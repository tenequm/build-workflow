# Role Directory and Permissions

This document outlines team roles within the queue-dispatcher project.

## Project Roles

### Steering Member
Steering members guide project direction and review architectural changes.

### Release Operator
Release operators manage deployment pipelines and production rollouts.

### Triage Contributor
Triage contributors organize issues, reproduce bugs, and manage labels.

## Communication Channels
- Steering discussions: `#queue-steering`
- Release notifications: `#queue-releases`
- Triage queries: `#queue-triage`
