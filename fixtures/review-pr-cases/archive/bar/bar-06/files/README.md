# gateway-router

High-throughput reverse proxy and HTTP gateway router.

## Getting Started

```bash
gateway-router --config config/gateway.conf
```

## Features
- Low-latency request routing.
- Configurable upstream timeouts and connection pooling.
- Health checking and circuit breaker support.
