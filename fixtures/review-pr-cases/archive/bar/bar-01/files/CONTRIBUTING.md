# Contributing Guide

Thank you for contributing to metrics-collector!

## Development Workflow
1. Fork the repository and create a feature branch.
2. Ensure all unit tests pass locally before opening a pull request.
3. Keep changes focused on a single topic.

## Coding Standards
- Format all Python code using `black` and `ruff`.
- Include docstrings for public classes and functions.
- Add unit tests under the `tests/` directory.

## Review Process
Pull requests are reviewed by designated maintainers based on the
affected subsystems.

Follow the review quorums specified in GOVERNANCE.md when coordinating
reviews with team members.

## Submitting Changes
Push your branch to GitHub and open a pull request against `main`.
Provide a clear description of your changes and reference any related
issues.
